# 解锁测试的逐项依据

所有请求均通过所选节点的独立临时内核进行。无需提供用户账号、登录 Cookie
或会员凭据。服务正常使用需要登录，不等于其地区接口也需要登录。

“地区检查通过”“日本站可访问”“方案已展示”“已定位”“注册市场”和
“样片可访问”分别表示不同证据，不能统称为完整解锁。

## 恢复项目

| 项目 | 匿名依据 | 结果范围及旧判定的问题 |
| --- | --- | --- |
| DMM | FANZA 日本站入口，使用年龄确认 Cookie | 仅确认可识别的日本站页面；登录、年龄确认、挑战页及异常响应不证明可用。海外版跳转不代表整个 DMM 不可用。 |
| DMM TV | `FetchClient { client { isForeignAccess } }` | 显式布尔值确认地区门禁；不再把播放器 `UNAUTHORIZED` 当作可播放证据。 |
| Disney+ | 匿名浏览器设备会话的 `inSupportedLocation` | 三次公开设备请求，不需要用户登录；只报告服务的地区标志，不按国家名单或日本特例覆盖它。公共浏览器客户端 key 不是用户凭据。 |
| DAZN | 启动接口的 `Region.isAllowed` | 只确认匿名启动地区判定；普通 403 不等于识别到代理。 |
| AbemaTV | `/v1/ip/check?device=android` 的 `isoCountryCode` 或明确错误码 | 只确认 IP 门禁；非日本地区不被推断为只能看海外节目。`anonymous_ip` 和 `blocked_location` 须来自结构化错误字段。 |
| YouTube Premium | `ytInitialData.contents` 中带价格标题和购买动作的方案卡片 | 仅说明公开方案已展示；国家字段、HTTP 200 或“无广告”文案都不能证明购买资格或会员功能。 |
| Netflix | 未登录页面的 `requestCountry.id` | 仅报告平台位置；标题页 200 不能证明可播放，两个标题页 404 不能证明“仅自制剧”。不再回退到任意 `country` 字段或 URL 语言地区。 |
| Amazon Prime Video | 页面明确返回的 `currentTerritory` | 仅报告平台位置；影片分级中的 `countryCode` 不能替代它。缺字段不是受限；明确限制标志/路径才表示限制。 |
| HBO Max | 匿名会话 `users/me` 的 `currentLocationTerritory` | 匿名设备 Cookie 可获得位置，不需要用户登录；缺少 routing 是无法确认，不是地区受限。主页支持市场链接不证明播放权益。 |
| Spotify | 注册入口同源重定向的市场路径 | 仅报告注册页市场；不提交注册、不创建账号，不声称注册成功或音乐可播放。 |

DMM TV 和 Abema 同时尝试 TCP 与经同一节点 SOCKS5 UDP 转发的 HTTP/3。
TCP、HTTP/3 判定冲突时显示“无法确认”；HTTP/3 传输无法建立时，可报告明确
标注的 TCP 结果。HTTP/3 已返回的异常响应不能被 TCP 成功结果掩盖。

## 暂不恢复的项目

| 项目 | 具体原因 | 是否证明检测必须登录 |
| --- | --- | --- |
| BBC iPlayer | 旧匿名 Media Selector 接口在本次可正常访问 Cloudflare 的日本、美国节点上均出现 TLS 连接失败，未取得可核实响应；旧逻辑仅搜索 `connection`，也未验证该连接属于所选直播及可访问的媒体。需取得当前接口的真实成功/地区拒绝响应后再恢复。 | 否。旧检测本身没有用户登录步骤；目前缺的是可验证的接口结果。 |
| 巴哈姆特动画疯 | 旧设备 ID、样本 token 流程也是匿名的，但本次同样未取得 TLS 连接后的响应。旧逻辑把没有 `animeSn` 的任何响应当作地区受限，会混淆登录要求、样本失效、接口变更和其他错误。需核实当前样本及明确错误字段。 | 否。匿名设备 ID 不等于用户登录。 |
| ChatGPT | 旧代码把 compliance 请求没有出现特定拒绝文本视为可用，再用 `ios.chat.openai.com` 的普通 403 推断手机客户端不可用。这两步均不足以证明实际对话或手机客户端能力。未恢复这种判定。 | 不能由旧检测作此结论；是否需要用户登录必须针对所测能力判断。 |
| Claude | 旧代码只要首页未跳转 `unavailable-in-region` 就认为可用，包括未知响应。Cloudflare trace 仅能报告位置，不能补足实际对话能力的验证。未恢复这种判定。 | 不能由旧检测作此结论；未取得可信的匿名对话能力检查。 |

连接失败只说明这些节点的这次请求未完成，不证明服务必须登录、接口全球失效
或该地区一定受限。这里保留逐项原因，避免以后把未验证项目再次统一归类。

## 本次验证

2026-10-11 使用 `data/config` 中的真实节点，在独立临时数据目录启动服务并
调用实际管理 API；不修改现用代理配置。日本、美国出口均通过 Cloudflare
位置查询确认。对恢复项目核实公开响应字段，并以相关单元测试及 Web 测试
覆盖成功、明确拒绝、未知响应及协议冲突。测试不保证账号或整个内容库可用。
